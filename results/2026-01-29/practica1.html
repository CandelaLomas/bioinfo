Práctica 1. Nociones de Bash y alineamientos básicos

Author

Candela Lomas Lara

Requisitos

Hacen falta los programas needle y water de EMBOS, el programa exonerate [@Slater2005], y el programa muscle[@Edgar2022]. Para la descarga automática de secuencias usaremos el programa wget. En sistemas operativos basados en Debian, seguramente se pueden instalar los cinco programas así (con privilegios administrativos):

Esta práctica se realiza a partir del terminal. Después de descargar el Ubuntu, inicia la práctica. Primero, se hace sudo apt update.

-sudo permite ejecutar comandos como administrado/root, es decir, permite instalar, desinstalar programas, modificar archivos…

-apt es como la App Store de Linux, para descargar los programas desde ahí.

-update es para actualizar la lista de paquetes, me muestra los que hay disponibles.

Una vez tenemos la lista, podemos empezar a instalas los programas que me pide, pero siempre con sudo porque, si no, no funciona.

El comando utilizado es el siguiente: sudo apt install -y emboss exonerate wget muscle

-y se utiliza para responder automáticamente sí a todas las preguntas durante la instalación, para que no vaya preguntando en cada programa si se quiere instalar (podría hacerse, pero esto es un atajo).

Luego, con which, se va comprobando que cada programa se ha instalado correctamente y DÓNDE. En este caso, todos los programas se han instalado en la carpeta bin (/usr/bin/*programa*).

apt install emboss exonerate wget muscle

needle y water (de EMBOSS): needle es para el alineamiento global de dos secuencias y water es para alineamiento local de dos secuencias.

exonerate es para el alineamiento flexible, permitiendo mapear exones, encontrar genes…

muscle es para el alineamiento múltiple de secuencias.

wget es para descargar archivos de internet directamente desde la terminal.

Alineamiento de pares de secuencia

En los enlaces siguientes encontrarás las secuencias descritas a continuación:

  • HumanChr17 Un fragmento del cromosoma 17 humano.
  • ChimpChr17 Un fragmento del cromosoma 17 de chimpancé, homólogo al anterior.
  • HumanSMARCD2 Tránscrito del gen SMARCD2 humano.
  • ChimpSMARCD2 Tránscrito del gen SMARCD2 de chimpancé.

El objetivo es alinear los tránscritos a sus respectivos fragmentos genómicos y comprobar que el alineamiento predice correctamente la estructura de intrones y exones del gen. Si las herramientas de EMBOSS están instaladas, podemos usar los programas needle o water para realizar el alineamiento desde la linea de órdenes mediante los algoritmos de Needleman-Wunsch o de Smith-Waterman, respectivamente. Puedes consultar la ayuda completa de estas herramientas ejecutando needle -help -verbose o water -help -verbose. Las órdenes siguientes descargan dos de las secuencias y las alinean con needle, a modo de ejemplo. El resultado del alineamiento debería guardarse en un archivo en formato de texto.

# Sólo queremos ejecutar el código si los resultados no están ya disponibles, es decir, si el archivo de salida no existe. No ejecutar el código automáticamente al renderizar 
if [ ! -e aln1.txt ]; then    
# Sólo descargaremos las secuencias, si no están ya descargadas. 
#Si no existe el archivo aln1.txt     
# -e: existe     
# !: No    
# Sirve para no repetir el análisis si ya se hizo antes.    
# este archivo es el resultado del alineamiento. 
if [ ! -e HumanSMARCD2.fa ]; then       
# Con la opción "-O" (letra mayúscula, no número cero) indicamos       
# el nombre del archivo donde queremos guardar la secuencia.      
wget -O HumanSMARCD2.fa https://www.ebi.ac.uk/ena/browser/api/fasta/AAI36323.1       #wget es para descargar       
     #-O es una opción de wget que sirve para especificar el nombre del archivo (que va después, justo antes de URL)    
     fi    
     if [ ! -e HumanChr17.fa ]; then       wget -O HumanChr17.fa \          https://rest.ensembl.org/sequence/region/human/17:63832000..63843000:1?content-type=text/x-fasta    fi    
     # Utilizamos el carácter "\" para que Bash ignore el salto de línea    # y poder distribuir los argumentos y opciones en más de una línea.    
   needle -asequence HumanChr17.fa \
          -bsequence HumanSMARCD2.fa \
          -gapopen 15.0 \
          -gapextend 0.5 \
          -auto \
          -outfile aln1.txt
fi
#el needle es para realizar los alineamientos de las secuencias.

Para alinear tránscritos o incluso proteínas a un genoma de referencia, es mejor usar el programa exonerate [@Slater2005], que puede aplicar los parámetros más adecuados para este tipo de tarea. Puedes leer la documentación de exonerate mediante las órdenes man exonerate o exonerate --help. También existe documentación online sobre este programa. En el bloque siguiente repetimos el mismo alineamiento que antes, con exonerate.

if [ ! -e HumanSMARCD2.fa ]; then    wget -O HumanSMARCD2.fa https://www.ebi.ac.uk/ena/browser/api/fasta/AAI36323.1 
fi 
if [ ! -e HumanChr17.fa ]; then    wget -O HumanChr17.fa \       https://rest.ensembl.org/sequence/region/human/17:63832000..63843000:1?content-type=text/x-fasta 
fi 
exonerate --model est2genome HumanSMARCD2.fa HumanChr17.fa

En este caso, el alineamiento resultante no se ha enviado a un archivo, sino al standard output, que Quarto recoge y presenta en este mismo documento. Por eso, no hemos condicionado la ejecución.

Con el comando model, para elegir qué tipo de secuencias estoy alineando y cómo. Luego, se pone est2genome, representa la secuencia que estoy alineando (de cDNA a DNA genómico)

Apéndice. Alineamientos múltiples

Un programa muy popular para alineamiento de múltiples secuencias es muscle [@Edgar2022]. Suponiendo que está instalado, vamos a probarlo con una colección de secuencias que pertenecen a la familia PF00009:

if [ ! -e PF00009.fa ]; then    wget -O PF00009.fa https://raw.githubusercontent.com/rcedgar/balifam/refs/heads/main/balifam100/in/PF00009.100 
fi  
if [ ! -e PF00009.afa ]; then    muscle -align PF00009.fa -output PF00009.afa 
fi

Si no existe el archivo, descarga las primera 100 secuencias de la familia y las guarda en formato fasta. Luego, las alinea con muscle y guarda el alineamiento. Alinea las 100 secuencias, no como antes que alineábamos dos.

Para visualizar el alineamiento, podemos usar la función BrowseSeqs(), del paquete DECIPHER en el entorno de R. Esta función nos permite enviar el alineamiento a un archivo HTML, que puede abrirse en una ventana nueva. Si estamos compilando un documento HTML, podemos incorporar el alineamiento en el mismo documento mediante la función includeHTML() del paquete htmltools, al precio de aumentar considerablemente su tamaño.

IMPORTANTE: esto está en lenguaje R, no en bash.

library('htmltools') 
library('DECIPHER') 
PF00009 <- readAAStringSet('PF00009.afa')
BrowseSeqs(PF00009, htmlFile = 'PF00009.html', openURL = FALSE) 
includeHTML('./PF00009.html')

Esto es para ver el alineamiento múltiple. Crea un HTML con colores para ver el alineamiento bien.

  • DECIPHER: Paquete de R para bioinformática (alineamiento, diseño de sondas…)

  • htmltools: Permite incrustar HTML en documentos RMarkdown.

    Luego, lee el archivo y lo guarda en R. Crea la visualización, mete ese HTML en R.
